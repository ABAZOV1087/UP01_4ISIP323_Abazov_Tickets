##  Описание выполненной работы

Настоящий проект представляет собой клиентское настольное приложение на платформе **WPF (.NET Framework)**, интегрированное с реляционной базой данных **Microsoft SQL Server (`DB_Abazov_Tickets`)** из **7 взаимосвязанных таблиц**. Приложение автоматизирует процессы ведения афиши мероприятий, учета концертных площадок, организаторов, промокодов, пользователей и продаж билетов, а также формирует аналитическую отчетность.

###  Ключевые возможности системы:
* 🔐 **Безопасная аутентификация и регистрация:**
  * Хеширование паролей пользователей по криптографическому алгоритму **`SHA1`**.
  * Строгая валидация пароля при регистрации и смене (не менее 6 символов, латинская раскладка, наличие минимум одной цифры).
  * Защита от перебора паролей (Brute-force): после **3 неудачных попыток входа** активируется модуль **CAPTCHA** с блокировкой команд копирования, вырезания и вставки (`Copy`/`Cut`/`Paste`) и отключенным контекстным меню.
* 👥 **Разграничение прав доступа по ролям:**
  * **Роль «Пользователь» (`User`):** просмотр каталога в виде карточек (`ListView` + `WrapPanel`) с подстановкой фото-заглушки (`TargetNullValue`), живой поиск по ФИО, фильтрация по роли и сортировка по алфавиту.
  * **Роль «Администратор» (`Admin`):** полный доступ ко всем **7 таблицам БД** (просмотр, поиск, фильтрация, сортировка, добавление, редактирование и каскадное удаление записей с подтверждением).
* 🎨 **Дизайн по Руководству по стилю (Style Guide) и смена тем:**
  * Интерфейс оформлен с использованием единого шрифта **`Open Sans`** и утвержденной фирменной палитры.
  * Реализовано динамическое переключение между **Фирменной (светлой)** и **Альтернативной (темной)** темами оформления с автоматическим сохранением выбора пользователя в файл конфигурации `theme.cfg` при выходе.
* 🛡️ **Контроль ввода и обратная связь:**
  * Все интерактивные элементы снабжены всплывающими подсказками (`ToolTip`), а поля ввода — интерактивными плейсхолдерами.
  * Настроены маски и ограничения ввода (запрет ввода букв в числовые поля, диапазонные ограничения на цену, вместимость площадки, процент скидки и количество билетов).
  * Подтверждение критических действий (`MessageBox` при удалении записей и при закрытии окна приложения).
* 📊 **Аналитика и экспорт отчетов:**
  * Интерактивное построение диаграмм (`System.Windows.Forms.DataVisualization.Charting`) с выбором пользователя и типа графика (`SeriesChartType`).
  * Автоматическая генерация отчетов в **Microsoft Word (`.docx`)** и **PDF (`.pdf`)** с разрывами страниц, таблицами расходов, выделением самого дорогого (темно-красный) и самого дешевого (темно-зеленый) билетов, а также верхними (текущая дата) и нижними (нумерация страниц) колонтитулами.
  * Автоматическая выгрузка сводных таблиц в **Microsoft Excel (`.xlsx`)** с разбивкой по листам пользователей, группировкой по категориям и расчетом итогов через формулы Excel (`=C*D`, `=SUM(...)`).

## 🗄️ Архитектура базы данных (`DB_Abazov_Tickets`)

База данных состоит из **7 таблиц** в третьей нормальной форме (3НФ) с настроенным каскадным удалением (`ON DELETE CASCADE`):

| № | Таблица | Назначение | Основные поля |
| :-: | :--- | :--- | :--- |
| 1 | **`User`** | Учетные записи пользователей системы | `ID` (PK), `Login`, `Password` (SHA1), `Role`, `FIO`, `Photo` |
| 2 | **`Category`** | Категории культурных и спортивных событий | `ID` (PK), `Name` |
| 3 | **`Venue`** | Площадки и стадионы проведения мероприятий | `ID` (PK), `Name`, `Address`, `Capacity` |
| 4 | **`Organizer`** | Юридические лица — организаторы событий | `ID` (PK), `Name`, `Phone`, `Email` |
| 5 | **`Event`** | Реестр мероприятий (Афиша) | `ID` (PK), `Title`, `CategoryID` (FK), `VenueID` (FK), `OrganizerID` (FK), `EventDate`, `AgeLimit` |
| 6 | **`Promocode`** | Скидочные купоны и промокоды | `ID` (PK), `Code`, `DiscountPercent`, `ValidUntil` |
| 7 | **`TicketSale`** | Операции продажи билетов клиентам | `ID` (PK), `UserID` (FK), `CategoryID` (FK), `EventID` (FK), `PromocodeID` (FK), `Date`, `Name`, `Num`, `Price` |
